# AIRI Playbook

### Agent Prompts & Operating Guidelines

A reusable Markdown library adapted from the AIRI assistant: working protocols, specialist
roles, memory policies, evidence standards and operational templates. Designed for people
building assistants that explain their work and respect data boundaries.

**Source-available · Personal and noncommercial use · No model or account required**

## Library

| Directory | Contents |
| --- | --- |
| `prompts/` | Core protocol, identity and communication principles |
| `agents/` | 12 specialist AIRI role prompts |
| `templates/` | User profile, task brief, memory/permission policy, research, camera privacy, Stock101 policy, journal, review, incident response and handoff |
| `docs/` | Adoption guidance and release validation |

## Get started

Download the repository, read [ADOPTION.md](docs/ADOPTION.md), and choose the instructions
your assistant needs. Connect them to the system-prompt mechanism of your actual host.
Fill example files in a private directory. Do not publish personal facts or credentials.

These are clean adaptations, not the original owner's private memories or conversation logs.
The library deliberately separates reusable behavior from personal settings. Markdown alone
cannot enforce a permission boundary; implement authentication and controls in application code.
