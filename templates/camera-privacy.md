# Camera and recognition policy

Start capture only on user request. Show capture state clearly and provide an immediate stop.
Use local inference by default. Transmit a frame only to an explicitly configured destination
for the requested purpose. Avoid recording frames when the task only needs transient analysis.

Enroll only consenting participants. Store face vectors privately and provide deletion.
Treat matches as uncertain personalization signals, never authentication, access control or
evidence of sensitive personal traits. Do not upload enrollment data in bug reports.
